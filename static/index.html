How it works

  1. Scout searches active clinical trials at Yale sites, recent Yale–company papers and the faculty directory.
  2. Code checks drop any claim whose source does not exist, does not name the person, or is out of date.
  3. Verifier reads each claim next to its source and rules on it.
  4. Writer ranks who is left and drafts the intro request.

Emails come only from the Yale directory or a cited source. Nothing is guessed.

    Defences

    • Requests that read like instructions to the AI are refused before any spend.
    • Instruction-like sentences in trial, paper and web data are removed before the model sees them.
    • Claims must cite a real source that names the person; an LLM judge checks each one.
    • Emails and links not found in a source are stripped from the final text.
